# Car Rental System - Admin Dashboard & Vehicle Management

This project is a module of a Car Rental Management System developed as part of an academic group project.

My contribution focused on the Admin Dashboard and Vehicle Management functionalities, including vehicle CRUD operations, availability management, image handling, and database integration using MongoDB.

## Features

- Add new vehicles
- Update vehicle information
- Delete vehicles
- Manage vehicle availability
- Upload vehicle images
- View vehicle details
- Fleet management

## Technologies

- React Native
- Node.js
- Express.js
- MongoDB
- Mongoose
